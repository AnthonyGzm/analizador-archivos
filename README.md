# Analizador Paralelo de Archivos de Texto (C#)

Proyecto final de Programacion Paralela. Analiza en paralelo los archivos
de texto de una carpeta (palabras, lineas, caracteres y frecuencia) y
compara el rendimiento secuencial vs paralelo.

## Estructura

- /src     Codigo fuente
- /tests   Pruebas
- /docs    Documentacion
- /metrics Resultados de las comparativas
